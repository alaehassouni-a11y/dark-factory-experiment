# THE PROTECTED PATHS, in one machine-readable place.
#
# This file is the canonical list. FACTORY_RULES.md §5 is its prose source:
# when the two disagree, §5 is what a human meant and this file is what the
# factory does, so fixing the drift is the first job. CLAUDE.md §"Protected
# paths", the PR template and the security-check command files all describe
# the same set in prose for a reader; none of them is read by a machine.
# This one is: .archon/workflows/dark-factory-validate-pr.yaml's
# check-protected-paths node matches every changed file in a PR against it
# and apply-verdict refuses to approve a PR that matched.
#
# Format, one glob per line:
#   glob     hard — a PR that touches this is auto-rejected (FACTORY_RULES §6.1)
#   ?glob    partial — only part of the file is an invariant, so the reviewers
#            read the diff instead. Reported as PROTECTED_PARTIAL, never blocking.
#   !glob    exemption, checked first.
# `**` and `*` both cross directory separators (the matcher is a shell `case`).
# Blank lines and lines starting with # are ignored.
