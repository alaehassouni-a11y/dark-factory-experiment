# About the Virtual Agent

The Virtual Agent is a spoken assistant. You can talk to it from the iPhone app in
French, English, German or Arabic, and it answers out loud in the language you used.

## What it knows

It answers first from this wiki, the folder of documents the business maintains. When
the wiki does not cover your question it searches the web and tells you that the answer
came from the web. If it cannot find an answer anywhere, it says so rather than guessing.

## How to talk to it

Tap the microphone, ask your question, and wait for the answer. You can also type. If
the agent cannot tell which language you are speaking, it will ask you to continue in one
of the four supported languages.
